## 一、安卓和 iPad 怎么“添加到主屏幕”
**Android 手机（Chrome）**
1. 用 Chrome 打开网址 https://xuanyu2035-lab.github.io/english-lab-app/ 。
2. 点右上角 ⋮ 菜单。
3. 选“添加到主屏幕”（或“安装应用”）→ 确认。桌面上就有 EnglishLab 图标，之后可离线打开。

**iPad（Safari）**
1. 用 Safari 打开同一个网址（要用 Safari，别的浏览器没有这个选项）。
2. 点顶部的“分享”按钮（方框加向上箭头）。
3. 选“添加到主屏幕”→ 点“添加”。

**第一次使用**：打开后点“选择 content.json 导入”，选你自己的内容包文件（用微信/云盘先传到手机或 iPad；每台设备导入一次）。内容包带图约 7.7MB，导入要几秒。录音和朗读第一次会询问浏览器权限，请允许。

**换设备时的进度**：“设置 → 导出进度”得到一个文件，传到另一台设备，再“设置 → 导入进度”。

## 八、第二轮改动：只聚焦两篇稿子，随时能跳、能选，声音改美式
（这一轮已重新部署到同一个网址 https://xuanyu2035-lab.github.io/english-lab-app/ ，私有仓库 english-lab 没有动，公开仓库里没有放你的真实内容。）

1. **首页只显示两篇稿子。** 词库、造句、一节课、难读词、参考页、设置、帮助都收进右上角“更多”，一个都没删。“今日推荐”改成可展开的小提示，只是建议。
2. **所有环节都能跳过。**
   - 每一句下面都有“先看懂 / 全文 / 挖空 / 只看线索 / 什么都不看”，点哪个直接到哪一级；还有“上一句 / 下一句”。
   - 每一句、每一小节都有“✅ 我会了”：直接做一次“什么都不看”的测试，说得出来就记为已会（这一节以后只在第 4、7 天各复习一次，比平时少）；说不出来就退回去练，并有“去练”按钮直达那一句。
   - 分块读、朗读、录音、休息、总结都可以不做；连说里每句有“跳过这句”，一节课里每段有“⏭ 跳过这段”。
3. **自己选练什么。** 小节卡片里展开“自己选”：整节从哪一级开始，或者挑任意一句开始（每句各有自己的级别按钮和“我会了”）。
4. **声音。** 默认美式英语，不用英式（只有设备上完全没有别的英文声音时才用英式）；自动优先选名字带 Natural / Neural / Enhanced / Premium 的声音。“更多 → 设置 → 声音”列出这台设备所有英文声音，每个都能试听并选定；语速 0.6–1.2 倍；每句重复 1–5 遍。使用说明和应用里的“帮助”页都用白话写了 iPad、安卓、Windows 怎么下载更自然的美式声音。
5. **验证。** `npm test` 现在 91 项全部通过（新增：声音挑选规则、跳级、“我会了”后的复习减少）。Playwright 在手机 360×800、390×844、平板 820×1180、电脑 1366×768 四种尺寸新增了：首页只有两篇稿子、跳级、“我会了”通过/不通过、整节“我会了”、跳过、声音设置（用模拟的语音引擎，保证美式优先、试听、语速、重复次数真的生效），全部通过，无横向溢出。
6. **还没在真机上验证的：** 真实的 iPad、安卓、Windows 上声音列表里具体有哪些声音，要你装好后自己看一眼；如果有声音名字带 Natural 却没排在前面，告诉我。
