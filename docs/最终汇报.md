## 一、安卓和 iPad 怎么“添加到主屏幕”
**Android 手机（Chrome）**
1. 用 Chrome 打开网址 https://xuanyu2035-lab.github.io/english-lab-app/ 。
2. 点右上角 ⋮ 菜单。
3. 选“添加到主屏幕”（或“安装应用”）→ 确认。桌面上就有 EnglishLab 图标，之后可离线打开。

**iPad（Safari）**
1. 用 Safari 打开同一个网址（要用 Safari，别的浏览器没有这个选项）。
2. 点顶部的“分享”按钮（方框加向上箭头）。
3. 选“添加到主屏幕”→ 点“添加”。

**第一次使用**：打开后点“选择 content.json 导入”，选你自己的内容包文件（用微信/云盘先传到手机或 iPad；每台设备导入一次）。内容包带图约 7.7MB，导入要几秒。录音和朗读第一次会询问浏览器权限，请允许。

**换设备时的进度**：“设置 → 导出进度”得到一个文件，传到另一台设备，再“设置 → 导入进度”。

## 三、本机版和便携版（没有网络时也可用）
- 双击 **`D:\EnglishLab\打开EnglishLab.cmd`**：弹出黑色窗口，浏览器打开 `http://localhost:4173/`。黑窗口关掉就是停止，进度存在浏览器里不会丢。（地址不同，进度和内容包是分开的：网址版和本机版各导入一次。）
- 双击 `打开EnglishLab(手机也能连).cmd`：同一个 Wi-Fi 下，手机输入窗口里显示的地址。因为不是加密网址，iPad 上不能离线和录音，只适合临时看一眼。
- 可搬走的文件夹 `D:\EnglishLab\EnglishLab-便携版\`（`npm run pack` 生成，约 163KB，只有程序）。
