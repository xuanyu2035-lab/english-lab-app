# EnglishLab 使用说明

网址：**https://xuanyu2035-lab.github.io/english-lab-app/**（手机、iPad、电脑都用这个）。

这是一个手机、平板、电脑都能打开的学习网页。先背**面试自我介绍**和 **4104 演讲开头**，再学**香港校园/职场/BIM 粤英夹杂词**。这个网址上只有程序和一个虚构示例；你的稿子和词库不在网上，只存在你自己的设备里。

## 十件事，照着做就行

1. **第一次：导入内容包。** 打开网址 → 点“选择 content.json 导入”→ 选你自己的内容包文件（每台设备、每个浏览器导入一次）。想先看看长什么样，可点“载入虚构示例”。
2. **回答三个问题。** 面试日期、4104 展示日期（不知道就勾“还不知道”，会先按 14 天倒排）；每次能练多久（30/60/90/120 分钟）；哪几节已经比较熟（不熟就都不勾）。以后可在“设置”里改。
3. **每天只做一件事：点“▶ 开始今天的课”。** 选好时长，App 自动排好几个 10–15 分钟的小段，段与段之间休息 1 分钟（可跳过），最后有一张“今天学会了什么”的总结卡——看到它，今天就可以放心收工。
4. **背稿是五步，别跳步：** ①先看懂（一句一屏，中英文）→ ②分块读（点一块读一块）→ ③抓线索 → ④逐级拿走提示（L1 看全文 → L2 挖空 → L3 只看线索 → L4 什么都不看）→ ⑤出声练：先听，再自己大声读、录音、回放，然后自评“顺 / 卡了一下 / 说不出来”。App 不打分，诚实自评就好。
5. **复习节奏已替你排好：** 每一节学会后，当天、第 2 天、第 4 天、第 7 天各复习一次，首页和“今天的课”会提醒。离面试/展示不到 3 天，自动变成“考前冲刺”，稿子占 70% 以上。
6. **4104 忘词不要停：** 稿子页里点“🆘 救场词”，看“原稿里的词 → 简单说法”和数字怎么读。“上台前确认清单”里的事（组员名字、数据来源等）要你自己确认并勾选。
7. **学词：** 按组学（不是按字母）。先想，再点“看意思”；然后点“记住了 / 还不熟”。每天新词默认 10 个、复习默认 40 个，多出来的自动顺延，**不会堆成“欠债”**。能配图的词有真实照片（下面有出处），抽象的词有一句“核心画面”帮你记。
8. **看清可信度标记：** “✔ 已核对”＝查过资料；“示范句，未逐条核对”＝按常见说法整理的示范句；“例句来自粵典，仅个人使用”＝只给自己用。每个词有“耳朵复核”：**我听过 / 没听过 / 说法不对**（可写一句），在“设置 → 导出反馈清单”导出，交给 GPT/Claude 去改内容。粤语字（例句里带虚线的）可以点，弹出普通话意思。
9. **造句与错→对：** “造句”里有骨架加槽（只换空格里的词）和拼句（把打散的词块排回原句）；“错 → 对卡片”先让你找哪里错，再看对的和原因。
10. **换设备 / 加新词：** “设置 → 导出进度”得到一个文件，用云盘传到另一台设备，再“导入进度”。要加新词：用 GPT/Claude 改 `content.json`，**只在末尾追加新条目、不改旧编号**，然后在每台设备“设置 → 导入内容包”重新导入一次，进度按编号保留。

## 添加到主屏幕（各三步）

**Android 手机（Chrome）**
1. 用 Chrome 打开网址。
2. 点右上角 ⋮ 菜单。
3. 选“添加到主屏幕”（或“安装应用”）→ 确认。

**iPad（Safari）**
1. 用 Safari 打开网址（不要用别的浏览器）。
2. 点顶部的“分享”按钮（方框加向上箭头）。
3. 选“添加到主屏幕”→ 点“添加”。

**Windows 电脑（Edge）**
1. 用 Edge 打开网址。
2. 点右上角 … 菜单 →“应用”。
3. 选“将此站点作为应用安装”→ 安装。

安装后即使没有网络也能打开；录音和朗读需要浏览器允许麦克风/语音（第一次会询问）。

## 小提醒
- 数据只在这台设备的浏览器里。清除浏览器数据会丢进度——换设备或清理前先“导出进度”。
- 朗读用浏览器自带的声音，没有对应声音时“🔊”按钮会自动隐藏。
- 图片出处：每张照片下面有一行小字，写明作者、许可证和来源（Wikimedia Commons）。
- 程序更新后，第一次打开可能要刷新一次页面才是最新版。
