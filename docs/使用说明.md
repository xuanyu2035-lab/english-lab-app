# EnglishLab 使用说明

网址：**https://xuanyu2035-lab.github.io/english-lab-app/**（手机、iPad、电脑都用这个）。

这是一个手机、平板、电脑都能打开的学习网页。首页只放两篇稿子：**面试自我介绍**和 **4104 演讲开头**。词库、造句、一节课、设置、帮助都收在右上角的“**更多**”里。这个网址上只有程序和一个虚构示例；你的稿子和词库不在网上，只存在你自己的设备里。

## 十件事，照着做就行

1. **第一次：导入内容包。** 打开网址 → 点“选择 content.json 导入”→ 选你自己的内容包文件（每台设备、每个浏览器导入一次）。想先看看长什么样，可点“载入虚构示例”。
2. **回答三个问题。** 面试日期、4104 展示日期（不知道就勾“还不知道”，会先按 14 天倒排）；每次能练多久（30/60/90/120 分钟）；哪几节已经比较熟（不熟就都不勾）。以后可在“设置”里改。
3. **自己选练什么。** 首页点哪一篇都行；进去后可以选哪一节、哪一句开始（展开“自己选：从哪一级、哪一句开始”）。首页的“今日推荐”只是建议，不用照做。想要自动排好的一套练习，到“更多 → ▶ 开始今天的课”：App 排好几个 10–15 分钟的小段，每一段、休息、总结都能跳过（顶部“⏭ 跳过这段”）。
4. **背稿的推荐顺序（不强制，哪一步都能跳）：** ①先看懂（一句一屏，中英文）→ ②分块读（点一块读一块）→ ③抓线索 → ④逐级拿走提示（L1 看全文 → L2 挖空 → L3 只看线索 → L4 什么都不看）→ ⑤出声练：先听，再自己大声读、录音、回放，然后自评“顺 / 卡了一下 / 说不出来”。App 不打分，诚实自评就好。
   - **跳到任意一级：** 每一句下面都有“先看懂 / 全文 / 挖空 / 只看线索 / 什么都不看”，点哪个就直接到哪一级（没有挖空词的句子没有“挖空”）。小节卡片里“自己选”可以让整节都从某一级开始，也可以挑任意一句开始，还有“上一句 / 下一句”。
   - **“我会了”：** 每一句和每一小节都有“✅ 我会了”。点了就直接做一次“什么都不看”的测试：说得出来（点“顺”）就记为已会，以后复习会少一些；说不出来就退回去练，并给你“去练”按钮。
   - 朗读、录音、休息、总结都可以不做，直接点下一步或“跳过”。
5. **复习节奏已替你排好：** 每一节学会后，当天、第 2 天、第 4 天、第 7 天各复习一次，首页和“今天的课”会提醒。离面试/展示不到 3 天，自动变成“考前冲刺”，稿子占 70% 以上。
6. **4104 忘词不要停：** 稿子页里点“🆘 救场词”，看“原稿里的词 → 简单说法”和数字怎么读。“上台前确认清单”里的事（组员名字、数据来源等）要你自己确认并勾选。
7. **学词：** 按组学（不是按字母）。先想，再点“看意思”；然后点“记住了 / 还不熟”。每天新词默认 10 个、复习默认 40 个，多出来的自动顺延，**不会堆成“欠债”**。能配图的词有真实照片（下面有出处），抽象的词有一句“核心画面”帮你记。
8. **看清可信度标记：** “✔ 已核对”＝查过资料；“示范句，未逐条核对”＝按常见说法整理的示范句；“例句来自粵典，仅个人使用”＝只给自己用。每个词有“耳朵复核”：**我听过 / 没听过 / 说法不对**（可写一句），在“设置 → 导出反馈清单”导出，交给 GPT/Claude 去改内容。粤语字（例句里带虚线的）可以点，弹出普通话意思。
9. **造句与错→对：** “造句”里有骨架加槽（只换空格里的词）和拼句（把打散的词块排回原句）；“错 → 对卡片”先让你找哪里错，再看对的和原因。
10. **换设备 / 加新词：** “设置 → 导出进度”得到一个文件，用云盘传到另一台设备，再“导入进度”。要加新词：用 GPT/Claude 改 `content.json`，**只在末尾追加新条目、不改旧编号**，然后在每台设备“设置 → 导入内容包”重新导入一次，进度按编号保留。

## 添加到主屏幕（各三步）

**Android 手机（Chrome）**
1. 用 Chrome 打开网址。
2. 点右上角 ⋮ 菜单。
3. 选“添加到主屏幕”（或“安装应用”）→ 确认。

**iPad（Safari）**
1. 用 Safari 打开网址（不要用别的浏览器）。
2. 点顶部的“分享”按钮（方框加向上箭头）。
3. 选“添加到主屏幕”→ 点“添加”。

**Windows 电脑（Edge）**
1. 用 Edge 打开网址。
2. 点右上角 … 菜单 →“应用”。
3. 选“将此站点作为应用安装”→ 安装。

安装后即使没有网络也能打开；录音和朗读需要浏览器允许麦克风/语音（第一次会询问）。

## 声音：默认美式英语，还能装得更自然
应用默认用**美式英语**，并自动优先选名字里带 Natural、Neural、Enhanced、Premium 的声音。到“更多 → 设置 → 声音”：列出这台设备上所有英文声音，每个都能“▶ 试听”，点“用这个”就选定；还能调**语速（0.6–1.2 倍）**和**每句重复次数（1–5 遍）**。应用里“更多 → 帮助”也有同样的说明。声音是设备自带的，装得越好就越自然：

**iPad / iPhone（Safari）**
1. 打开 设置 → 辅助功能 → 朗读内容 → 声音 → 英语。
2. 选 “English (United States)”（美国英语），找名字后面带“增强版 / Enhanced”或“高级 / Premium”的声音（比如 Ava、Samantha、Evan），点右边的下载图标，等它下载完。
3. 回到 EnglishLab：设置 → 声音，点“试听”，满意就点“用这个”。

**安卓手机 / 平板（Chrome）**
1. 打开 设置 → 系统（或“更多设置”）→ 语言和输入 → 文字转语音（TTS）输出。
2. “首选引擎”选“Google 语音服务”，点旁边的齿轮 → 安装语音数据 → 英语（美国），下载你喜欢的美式声音。
3. 回到 Chrome 里的 EnglishLab，关掉再重新打开一次；设置 → 声音 里就会看到新的声音。不同品牌手机菜单名字略有不同。

**Windows 电脑**
1. 最推荐：用 Microsoft Edge 打开 EnglishLab。Edge 自带一批名字里带“Natural”的美式在线声音（例如 Aria、Jenny、Guy），最自然；需要联网。
2. 想用 Chrome 或不联网：打开 设置 → 时间和语言 → 语音 → 管理语音（或“添加语音”）→ 选 English (United States) 下载。
3. 回到 EnglishLab：设置 → 声音 → 试听几个，选一个“en-US（美式）”的。

## 小提醒
- 数据只在这台设备的浏览器里。清除浏览器数据会丢进度——换设备或清理前先“导出进度”。
- 朗读用设备自带的声音，没有英文声音时“🔊”按钮会自动隐藏。声音怎么选、怎么装得更自然，见下面“让声音更自然”。
- 图片出处：每张照片下面有一行小字，写明作者、许可证和来源（Wikimedia Commons）。
- 程序更新后，第一次打开可能要刷新一次页面才是最新版。
